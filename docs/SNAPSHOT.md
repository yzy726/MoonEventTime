# 快照格式 v1

UTF-8 JSON 根字段固定为 format_version、fingerprint、config、watermark_ms、finished、windows。Int64 全部用规范十进制字符串，初始水位线为 null。窗口数组按 end/start/UTF-8 key 排序，每项含 key/start_ms/end_ms/count/sum/min/max。

fingerprint 是版本、宽度、原点及五项预算的显式规范组合，用于配置一致性判断，不是签名或校验和。恢复还对照完整配置；预算变化也须显式迁移。

恢复先检查字节数和最多 16 层嵌套，再校验格式、版本、配置和每个窗口。拒绝重复/逆序/已关闭窗口、非法键、端点错位、恶意整数、超限状态。统计要求 count>0、min<=max，数量、总和与实际出现的极值相容；用 BigInt 避免校验乘法溢出。终止状态不能保留活跃窗口。全部通过才返回新引擎。

快照包含业务键和统计值，调用方负责脱敏、权限和加密。CLI 独占创建同目录临时文件，完整写入后原子替换目标，失败保留已有目标；不承诺 fsync、断电持久性或外部事务一致性。

正确恢复需要协调已确认输入偏移、状态和下游输出。快照与输出确认不同步可能重复输出；重放已累计前缀会重复计数。prefix/restore/suffix 示例只证明同一确认边界下的恢复等价。
