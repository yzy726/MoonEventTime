# 事件时间语义

时间戳、原点和宽度为 Int64 毫秒；宽度为正。起点等价于 `origin+floor((timestamp-origin)/size)*size`；实现用同余偏移避免中间减法溢出。数学端点不可表示时返回 TimeOverflow，不回绕。窗口为 `[start,end)`。

键非空，长度按 UTF-8 字节计算；不做 Unicode 规范化或大小写转换。结果按 end、start、UTF-8 字节序排序，一个非空 `(key,start,end)` 只有一个统计状态。

水位线 W 为排他边界，按 end<=W 关闭窗口。例：size=60000、W=45000 时 timestamp=12000 仍可接收；W=60000 后侧输出。重复 W 幂等，回退返回 WatermarkRegression。已关闭状态立即删除；即使某个旧键此前从未出现，其旧窗口事件仍是迟到。引擎不累积迟到队列。

finish 与最大水位线分开表示。成功后终止，重复调用返回 Finished；失败的 finish 不终止。无事件窗口不输出。

count 为正，sum/min/max 为精确 Int64。每次 count+1、sum+value 预检，全部通过才替换不可变统计值。到达顺序变化在所有中间和可表示的前提下保持结果一致；最终和可表示并不保证每种顺序均可接收。

非法键、溢出、预算拒绝和水位线回退都不修改状态或进度。输出先收集有界到期前缀，再统一删除与推进；预算不足可分段推进后重试。原子性只覆盖一次库调用，不包含外部输出或文件事务。
